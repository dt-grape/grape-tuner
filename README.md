# grapetuner

Гитарный и хроматический PWA-тюнер. Он обрабатывает микрофонный сигнал на устройстве и после первой успешной загрузки работает без интернета.

- 17 уникальных гитарных строев, поиск, избранное и собственные строи. Full Step Down — альтернативное название D Standard.
- Автоматический и ручной выбор струны, отметки о настройке и сброс прогресса.
- Хроматический режим, обозначения через диезы и бемоли, калибровка A4 от 415 до 466 Гц и настраиваемый допуск от 1 до 10 центов.
- Русский и английский интерфейс, системная, светлая и тёмная темы. Настройки и строи сохраняются в LocalStorage.

## Запуск

Нужны Node.js 22.12+ из ветки 22 или Node.js 24 LTS и npm.

```sh
npm ci
npm run dev
```

Откройте адрес localhost, который напечатает Vite. Включите микрофон кнопкой тюнера и разрешите доступ в браузере. Для проверки с телефона нужен HTTPS. Локальный HTTP по IP компьютера не считается безопасным контекстом.

## Проверки и сборка

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

Сборка сохраняется в `dist` и по умолчанию использует префикс `/grape-tuner/`. При предпросмотре используйте URL, который напечатает Vite. Сервис-воркер работает в production-сборке. Дождитесь сообщения о готовности офлайн, затем отключите сеть и перезагрузите страницу для проверки. При наличии обновления приложение предлагает установить его после остановки микрофона.

Для другого префикса задайте переменную окружения `PAGES_BASE` перед сборкой, например `/my-repo/` или `/` для корня домена.

## GitHub Pages

Целевой репозиторий — [dt-grape/grape-tuner](https://github.com/dt-grape/grape-tuner). Отправьте локальную ветку командой `git push -u origin main` и выберите **Settings → Pages → Build and deployment → Source → GitHub Actions**. Если первый запуск начался до включения Pages, запустите workflow вручную из **Actions → Deploy grapetuner → Run workflow**.

Workflow устанавливает зависимости через `npm ci`, проверяет типы, запускает тесты, собирает проект с путём, который сообщает GitHub Pages, и публикует `dist`. Ожидаемый адрес проекта — [dt-grape.github.io/grape-tuner/](https://dt-grape.github.io/grape-tuner/).

## Микрофон и установка

На поддерживаемых браузерах кнопка установки видна внизу экрана и в настройках. На iPhone и iPad откройте приложение в Safari и воспользуйтесь **Поделиться → На экран «Домой»**.

После блокировки экрана или переключения приложения браузер может приостановить аудио. Если тюнер показывает паузу после возврата, нажмите кнопку возобновления. Вибрация доступна в браузерах с поддержкой Vibration API.

Распознавание рассчитано на одиночные ноты от 40 до 2000 Гц. Для устойчивого измерения приглушайте остальные струны. Аудио не записывается и не передаётся по сети.
